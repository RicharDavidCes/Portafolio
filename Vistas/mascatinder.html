MascaTinder

Plataforma de interacción y conexión social vinculada a la comunidad estudiantil de la UCV

Stack & Tecnologías Utilizadas

HTML5 CSS3 JavaScript Supabase

Descripción del Proyecto

MascaTinder es una aplicación web interactiva desarrollada para dinamizar la interacción social entre los miembros del canal humorístico "www.Losmascapipes.UCV". La plataforma actúa como un punto de encuentro digital que facilita la publicación, exploración y conexión entre perfiles de forma rápida y moderna.

El desarrollo utiliza Supabase como Backend-as-a-Service (BaaS) para la gestión del almacenamiento de archivos, autenticación y persistencia de datos, junto con una interfaz liviana construida en Vanilla JavaScript.

Módulos Claves & Características:

  • Integración con Supabase: Base de datos relacional para el registro interactivo de publicaciones y la gestión centralizada de perfiles.
  • Chat en Tiempo Real: Implementación de suscripciones de Supabase para permitir mensajería instantánea y fluida entre usuarios.
  • Autenticación & Recuperación de Cuenta: Flujo seguro de gestión de usuarios con recuperación de credenciales mediante correo electrónico.
  • Feed de Tarjetas Interactivas: Sistema dinámico para la navegación y visualización de perfiles procesado desde el cliente con JavaScript.
  • Diseño Adaptativo & Moderno: Interfaz con estética de aplicación móvil, completamente optimizada para cualquier pantalla.
