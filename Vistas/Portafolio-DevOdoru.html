Descripción del Proyecto

Portafolio Devodoru es una plataforma web desarrollada a la medida para exhibir proyectos de desarrollo de videojuegos independientes. El sistema combina una landing page atractiva para los jugadores con una suite administrativa robusta para la gestión del catálogo.

El backend está soportado por Supabase, utilizando su base de datos relacional PostgreSQL, su motor de autenticación segura y el bucket de almacenamiento multimedia para gestionar capturas y recursos de cada título publicado.

Portafolio DevOdoru

Módulos y Características Clave:

  • Landing Page & Tarjetas de Showcase: Muestra cada videojuego mediante una vista previa interactiva con título, descripción detallada, galería lateral de capturas y enlace directo a la plataforma externa de descarga (Itch.io, Steam, etc.).
  • Autenticación Segura con Supabase Auth: Acceso restringido al panel de administración mediante verificación por tokens de sesión. Cuenta con un sistema de recuperación de contraseña por correo electrónico.
  • Panel Administrativo CRUD: Módulo exclusivo desde el cual el desarrollador puede publicar nuevos lanzamientos, actualizar la información existente o eliminar proyectos de forma instantánea.
  • Gestión de Multimedia (Supabase Storage): Carga y optimización dinámica de imágenes promocionales y screenshots desde el cliente hacia la nube.
  • Diseño Adaptativo: Experiencia optimizada para navegar el catálogo de juegos tanto en dispositivos móviles como en pantallas de escritorio.
